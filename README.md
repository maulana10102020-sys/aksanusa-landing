# AksanusA Landing Page

Landing page statis (1 file HTML, tanpa build step) untuk AksanusA App Development.

## Menjalankan lokal
Buka langsung `index.html` di browser, atau jalankan server statis sederhana:

```bash
npx serve .
```

## Deploy ke Vercel
Lihat langkah-langkah di percakapan / dokumentasi tim.
